# 📖 Folio — کاتالوگ ورق‌زن سه‌بعدی

**نمایش کاتالوگ و دفترچه‌ی محصولات به‌صورت یک مجله‌ی سه‌بعدیِ واقعی روی وب‌سایت وردپرسی.**

ورق‌زدن با کشیدنِ موس/انگشت روی خودِ کاغذ، پیچ‌خوردنِ گوشه، سایه‌ی نرم و صدای ورق — سریع، بدون هنگ و کاملاً فارسی (راست‌به‌چپ).

## ✨ ویژگی‌ها

- 📚 **ورق‌زدن سه‌بعدیِ واقعی** — موتور [StPageFlip](https://github.com/Nodlik/StPageFlip)؛ کشیدنِ موس/انگشت روی کاغذ، پیچِ گوشه و سایه‌ی نرم (روی GPU، بدون هنگ).
- 🖼️ **دو منبعِ محتوا** — یا تصاویرِ صفحه‌ها از کتابخانه‌ی رسانه، یا یک فایل **PDF** که سمتِ مرورگر با [PDF.js](https://mozilla.github.io/pdf.js/) رندر می‌شود (بدون نیاز به Ghostscript/Imagick روی سرور).
- 🔍 **بزرگ‌نمایی و جابه‌جایی (Zoom / Pan)** — دکمه، `Ctrl + چرخِ موس`، pinchِ دوانگشتی و کلیدهای `+` / `−` / `0`.
- 🚀 **ارتقای تدریجیِ کیفیت** — لودِ اولیه سبک می‌ماند و پس از آماده‌شدن، تصویرها در پس‌زمینه و بدون پرش به کیفیتِ اصلی می‌رسند (سازگار با Save-Data).
- 🌐 **راست‌به‌چپ + WPML** — جهتِ خودکار بر اساس زبانِ صفحه (فارسی=RTL، انگلیسی=LTR)؛ کاتالوگ‌ها و متاها قابلِ ترجمه.
- 🖥️ **تمام‌صفحه** با صحنه‌ی تاریکِ گالری و کنترل‌های شیشه‌ای شناور.
- 🔊 **صدای اختیاریِ ورق** (WebAudio، بدون فایل صوتی).
- ⚡ **بارگذاری هدفمند** — اسکریپت و استایل فقط در صفحه‌هایی که شورت‌کد دارند لود می‌شوند.
- ♿ سازگار با `prefers-reduced-motion`.

---

## 📦 نصب

1. پوشه‌ی `folio-flipbook` را در مسیر `wp-content/plugins/` قرار بده.
2. از پیشخوانِ وردپرس → **افزونه‌ها**، افزونه‌ی **Folio** را فعال کن.

---

## 🚀 استفاده

1. از منوی **«کاتالوگ ورق‌زن»** یک کاتالوگ جدید بساز و عنوان بگذار.
2. در باکسِ **«صفحاتِ کاتالوگ»** تصاویرِ صفحه‌ها را انتخاب و با کشیدن مرتب کن (اولین تصویر = جلد) — یا یک فایل PDF بگذار.
3. از باکسِ **«تنظیماتِ نمایش»**، جهت، حالت، انیمیشنِ ورود و صدا را تنظیم کن.
4. کاتالوگ را ذخیره کن و شورت‌کدِ آماده را در هر برگه/نوشته/ویجت بگذار:

```text
[flip_catalog id="123"]
```

## ⚙️ تنظیمات

| گزینه | مقادیر | توضیح |
|---|---|---|
| منبع | `images` / `pdf` | تصاویرِ صفحه یا فایلِ PDF |
| جهت | `auto` / `rtl` / `ltr` | خودکار (بر اساس زبانِ صفحه) یا اجباری راست‌به‌چپ / چپ‌به‌راست |
| حالت | `book` / `single` | جلدِ تنها → دوصفحه‌ای، یا همیشه تک‌صفحه |
| انیمیشنِ ورود | `settle` / `sweep` / `unfold` / `rise` / `fade` / `none` | جلوه‌ی باز شدنِ کتاب |
| پس‌زمینه | `none` / `light` / `dark` / `wood` | بستر پشتِ کتاب |
| صدا | `on` / `off` | صدای ورقِ کاغذ |

## 🎛️ کنترل‌ها

| کنترل | عملکرد |
|---|---|
| کشیدن روی کاغذ / کلیک / swipe | ورق‌زدن |
| دکمه‌های `‹` `›` یا فلش‌های صفحه‌کلید | صفحه‌ی قبل/بعد |
| دکمه‌ی `+` `−` / `Ctrl + wheel` / pinch | بزرگ‌نمایی و کوچک‌نمایی |
| کلیدهای `+` `−` `0` | بزرگ‌نمایی، کوچک‌نمایی، بازنشانی |
| دکمه‌ی تمام‌صفحه | نمایشِ سینمایی |

## 🌐 چندزبانگی (WPML)

نوعِ محتوای `flip_catalog` قابلِ ترجمه است و شورت‌کد با `wpml_object_id` به‌صورتِ خودکار به نسخه‌ی زبانِ جاری سوییچ می‌کند. کاتالوگ صفحه‌ی مستقل ندارد و در نتایجِ جست‌وجو ایندکس نمی‌شود — فقط داخلِ محتوا با شورت‌کد نمایش داده می‌شود.

---

## 🧱 پشتِ صحنه

- **StPageFlip** روی canvas رندر می‌کند؛ برای RTL، آرایه‌ی تصاویر برعکس و از جلد شروع می‌شود.
- **PDF.js** هر صفحه را به‌صورتِ پیش‌رونده به تصویر تبدیل می‌کند (با نوارِ پیشرفت، بدون هنگ).
- ارتقای کیفیت با پیش‌بارگذاریِ نسخه‌ی `full` در `requestIdleCallback` و جایگزینیِ مستقیمِ تصویرِ صفحه انجام می‌شود (بدون flashِ لودر).
